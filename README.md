# Logistic Regression ML Project

Logistic Regression ML Project is a machine learning project developed as a final assessment in a Machine Learning course.

The project applies logistic regression to a dataset, including data analysis, model training, evaluation, and prediction.

## Project Description

This project was developed as part of a Machine Learning course.

The project focuses on implementing and analyzing a logistic regression model using Python and Jupyter Notebook.

The project includes:

- Dataset loading and exploration
- Data preprocessing
- Logistic regression model implementation
- Model training and testing
- Accuracy evaluation
- Result analysis
- Questions and answers file
- Requirements file for required Python packages
